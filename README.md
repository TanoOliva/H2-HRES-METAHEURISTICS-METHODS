# Tesis - Optimizacion de un sistema WPEB con metaheuristicas

Contenido de la tesis:

- **notebooks/H2_HRES_trabajo.ipynb** - Notebook ejecutable con toda la investigacion
- **notebooks/src/hourly_2008.csv** - Datos horarios necesarios para el notebook

## Como ejecutarlo

Requisitos: `numpy`, `pandas`, `matplotlib`, `scipy`

```bash
pip install numpy pandas matplotlib scipy
jupyter notebook notebooks/H2_HRES_trabajo.ipynb
```

Luego selecciona 'Run All' en el notebook.
